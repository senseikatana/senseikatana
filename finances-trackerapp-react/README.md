# Finanzas Tracker App

Control total de tus finanzas personales y de negocio.

## Caracteristicas

### Finanzas Personales
- Dashboard con resumen
- Ingresos y Gastos Fijos/Variables
- Suscripciones y Registro Diario
- Presupuestos, Metas de Ahorro, Deudas

### Finanzas de Negocio
- Ingresos y Gastos del Negocio
- Presupuesto Negocio

### Herramientas
- Tickets y Recibos (subir fotos/PDFs)
- CRM de contactos
- Categorias personalizables
- Asistente IA

## Tech Stack

- Next.js 16 (App Router + Turbopack) + React 19
- Tailwind CSS 4
- Firebase Auth + Firestore (opcional)
- NVIDIA NIM (GLM-5.2)

## Inicio Rapido

1. npm install
2. (Opcional) Configura .env con Firebase
3. npm run dev
4. Abre http://localhost:3000

## Estructura

- app/ - Next.js App Router
- src/ - Componentes y logica
- public/ - Assets estaticos
