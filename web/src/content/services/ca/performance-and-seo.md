## Quin problema resol

Un web pot veure's bé i tot i així perdre visites: tarda a pintar, trenca la hidratació o té tres URLs per al mateix contingut. El problema poques vegades és només "SEO".

Treballo sobre les causes mesurables: pes de JavaScript, imatges, fonts, renderitzat i estructura d'enllaçament. Després es decideix què optimitzar amb dades, no amb intuïció.

## Com ho abordo

- **Mesurar abans de tocar**: línia base de Core Web Vitals i de l'embut real.
- **Pressupost de rendiment**: cada ruta té un sostre; si el passa, no entra.
- **SEO tècnic correcte**: una URL canònica per idioma, `hreflang` consistent, sitemap i metadades.
- **Sense promeses de posició**: el rànquing depèn de factors que no controlo. El que sí puc controlar és la base tècnica i la mesura.

## Per a qui no és

No és per a qui busca garantir el primer lloc de Google. Això no és un lliurable honest, i no ho venc així.
