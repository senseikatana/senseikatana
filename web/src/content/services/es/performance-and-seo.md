## Qué problema resuelve

Una web puede verse bien y aun así perder visitas: tarda en pintar, rompe la hidratación o tiene tres URLs para el mismo contenido. El problema rara vez es solo "SEO".

Trabajo sobre las causas medibles: peso de JavaScript, imágenes, fuentes, renderizado y estructura de enlazado. Después se decide qué optimizar con datos, no con intuición.

## Cómo lo abordo

- **Medir antes de tocar**: línea base de Core Web Vitals y del embudo real.
- **Presupuesto de rendimiento**: cada ruta tiene un techo; si se pasa, no entra.
- **SEO técnico correcto**: una URL canónica por idioma, `hreflang` consistente, sitemap y metadatos.
- **Sin promesas de posición**: el ranking depende de factores que no controlo. Lo que sí puedo controlar es la base técnica y la medición.

## Para quién no es

No es para quien busca garantizar el primer puesto de Google. Eso no es un entregable honesto, y no lo vendo así.
