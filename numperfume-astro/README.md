# NUM Perfumes Project

Welcome to the **NUM Perfumes** repository! This project serves as the digital storefront and web platform for NUM Perfumes, a brand dedicated to offering high-quality equivalent fragrances and inspired perfumes for every moment.

## 🌟 About NUM Perfumes
NUM Perfumes is an exclusive perfume house specializing in high-quality alternative fragrances ("equivalencias"). We believe that everyone deserves to wear premium, long-lasting scents inspired by their favorite designer and niche fragrances, but at a more accessible price point. 

Our catalog features a carefully selected collection of fragrances available in 50ml and 100ml sizes, from refreshing gourmands to deep, definitive masculine and feminine scents. Every order is prepared with care, including detailed descriptions and mini-catalogs to help you discover your next signature scent.

For more information, visit our official website: [https://numperfumes.com](https://numperfumes.com)

## 🚀 Project Structure

This project is built using **Astro**, a modern web framework that provides exceptional performance and excellent developer experience.

```text
/
├── public/           # Static assets like images and fonts
├── src/
│   ├── assets/       # Processed assets
│   ├── components/   # Reusable UI components (buttons, product cards)
│   ├── layouts/      # Page wrappers and shared layouts
│   └── pages/        # File-based routing (e.g., index.astro, products.astro)
└── package.json      # Project dependencies and scripts
```

## 🧞 Local Development Commands

To run this project locally, make sure you have [Bun](https://bun.sh/) (or npm/yarn/pnpm) installed. Run these commands from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `bun install`             | Installs all project dependencies                |
| `bun dev`                 | Starts local dev server at `localhost:4321`      |
| `bun build`               | Builds the production site to `./dist/`          |
| `bun preview`             | Previews your build locally before deploying     |
